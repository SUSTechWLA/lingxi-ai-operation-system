# Stage: viewpoint_dossier

将用户的粗略想法转化为结构化的观点档案，为后续口播稿写作和视频制作提供核心创意基础。

## 输出格式

输出结构化 JSON，包含以下字段：

```json
{
  "核心观点": "一句话核心论点（必须是可争论的，而非中性说明）",
  "目标观众": "谁会感觉'这是在说我'",
  "开场触发场景": "一个具体的日常时刻，用于视频开头",
  "核心张力": "视频挑战的常见信念或行为",
  "论证材料": "个人观察、案例、类比、数据点",
  "最强反方观点": "最合理的反对意见",
  "边界": "本视频不主张什么（明确限定范围）",
  "情绪弧线": "从开场情感到结尾情感的走向",
  "结尾落点": "观众应该记住的最后一句或行动",
  "形式规格": {
    "平台": "抖音/小红书/YouTube Shorts",
    "画幅": "9:16 竖屏 / 16:9 横屏",
    "目标时长": "60秒 / 90秒 / 120秒",
    "语言": "中文 / 英文"
  },
  "Assumptions": "标注推断的细节"
}
```

## 质量规则

- 核心观点必须可争论——如果所有人都同意，说明观点不够锋利
- 倾向于一个具体开场场景，而非泛泛引入
- 保留用户态度和立场，不变成中性知识说明
- 档案紧凑，足够驱动后续脚本写作即可
- 在一键/默认模式下做出保守推断，在 Assumptions 中标注

## 禁止事项

- 不写成中性科普或知识说明
- 不创建超 500 字的冗长档案
- 不在观点档案中加入画面/镜头/字幕等制作指令
- 不替用户改变立场或主题方向
