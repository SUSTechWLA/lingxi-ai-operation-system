# 躺营导演台 v1.0-beta 最后一轮关键优化方案

## 1. 当前关键问题

当前系统已经基本具备：

```text
1. 躺营导演台前端主界面
2. 十阶段 / 十角色创作流程
3. ArtifactIndex 状态字段
4. 下游 stale 链路
5. RenderDependencyGuard
6. PackageGuard
7. LocalJob Artifact Sync
8. Runtime E2E 初版
```

但正式用户内测前仍有 4 个关键风险：

```text
P0-1：审核通过后，artifact.humanApproved 可能没有被置为 true
P0-2：HYPERFRAMES_RENDER 输出 VIDEO artifact 可能因缺 unitId 被 Cloud 跳过
P0-3：RenderDependencyGuard 按 stage 查产物，不够精确
P0-4：Runtime E2E 还需要覆盖 artifact sync 与 approve artifact 场景
```

最终目标：

```text
1. 用户点“通过”后，对应产物必须 humanApproved=true
2. 本地渲染完成后，VIDEO artifact 必须进入 ArtifactIndex
3. 渲染门禁必须精确检查 HYPERFRAMES_PROJECT 和 PREVIEW_SNAPSHOTS
4. 测试能证明 final.mp4 从 LocalJob 回写到 Cloud
```

# 2. P0-1：修复审核通过后产物未确认问题

## 2.1 当前风险

当前 `ApproveReview` 依赖 review node input 中的：

```text
artifactId
```

如果 review node 没带 `artifactId`，则：

```text
用户点击通过
  ↓
review 状态通过
  ↓
artifact.humanApproved 没有更新
  ↓
RenderDependencyGuard 认为视频结构或预览未确认
  ↓
最终渲染被阻断
```

正式内测版不能依赖 review node 一定提前知道 artifactId。

---

## 2.2 目标逻辑

审核通过时按以下优先级确认产物：

```text
优先级 1：node.input.artifactId
优先级 2：projectID + stage + artifactKinds
优先级 3：projectID + sourceNode + artifactKinds
```

也就是说：

```text
有 artifactId → 直接确认该产物
没有 artifactId → 找当前项目、当前阶段、当前产物类型的最新产物
```

## 2.3 新增 ArtifactService 方法

新增：

```go
func (s *Service) ApproveCurrentArtifactsByStageAndKinds(
    ctx context.Context,
    projectID string,
    stageName string,
    artifactKinds []string,
    reviewerID string,
) ([]string, error)
```

实现逻辑：

```go
func (s *Service) ApproveCurrentArtifactsByStageAndKinds(
    ctx context.Context,
    projectID string,
    stageName string,
    artifactKinds []string,
    reviewerID string,
) ([]string, error) {
    if projectID == "" || stageName == "" || len(artifactKinds) == 0 {
        return nil, nil
    }

    approvedIDs := make([]string, 0)

    for _, kind := range artifactKinds {
        artifact, err := s.repo.FindCurrentByStageAndKind(ctx, projectID, stageName, kind)
        if err != nil {
            return approvedIDs, err
        }
        if artifact == nil {
            continue
        }

        if artifact.Status == ArtifactStatusStale ||
           artifact.Status == ArtifactStatusRejected ||
           artifact.Status == ArtifactStatusFailed {
            continue
        }

        if err := s.repo.UpdateHumanApproved(ctx, artifact.ID, true, reviewerID); err != nil {
            return approvedIDs, err
        }

        approvedIDs = append(approvedIDs, artifact.ID)
    }

    return approvedIDs, nil
}
```

## 2.5 Handler 修改

修改 `approveReviewedArtifact`。

当前逻辑大概是：

```go
artifactID := nodeInputString(node, "artifactId")
if artifactID == "" {
    return
}
artifactService.ApproveArtifact(ctx, artifactID, reviewerID)
```

改为：

```go
func (h *Handler) approveReviewedArtifact(
    ctx context.Context,
    run *DAGRun,
    node *DAGNode,
    reviewerID string,
) {
    if h.artifactService == nil || node == nil {
        return
    }

    // 1. 优先 artifactId
    artifactID := nodeInputString(node, "artifactId")
    if artifactID != "" {
        if err := h.artifactService.ApproveArtifact(ctx, artifactID, reviewerID); err != nil {
            h.logger.Warn("approve artifact by id failed",
                "artifactId", artifactID,
                "err", err,
            )
        }
        return
    }

    // 2. fallback：projectID + stage + artifactKinds
    projectID := h.resolveProjectID(run)
    stageName := nodeInputString(node, "stage")
    artifactKinds := nodeInputStringSlice(node, "artifactKinds")

    if len(artifactKinds) == 0 {
        artifactKinds = nodeInputStringSlice(node, "requiredOutputs")
    }

    if projectID == "" || stageName == "" || len(artifactKinds) == 0 {
        h.logger.Warn("approve artifact skipped: missing fallback fields",
            "projectID", projectID,
            "stage", stageName,
            "artifactKinds", artifactKinds,
            "nodeID", node.ID,
        )
        return
    }

    approvedIDs, err := h.artifactService.ApproveCurrentArtifactsByStageAndKinds(
        ctx,
        projectID,
        stageName,
        artifactKinds,
        reviewerID,
    )
    if err != nil {
        h.logger.Warn("approve artifacts by stage and kinds failed",
            "projectID", projectID,
            "stage", stageName,
            "artifactKinds", artifactKinds,
            "err", err,
        )
        return
    }

    h.logger.Info("approved artifacts by stage and kinds",
        "projectID", projectID,
        "stage", stageName,
        "artifactKinds", artifactKinds,
        "approvedIDs", approvedIDs,
    )
}
```

# 4. P0-3：RenderDependencyGuard 精确检查 Stage + Kind

## 4.1 当前风险

当前 RenderDependencyGuard 主要按 stage 查：

```text
composition stage
preview stage
```

但 preview stage 可能有多个产物：

```text
HYPERFRAMES_PROJECT
PREVIEW_SNAPSHOTS
PREVIEW_REPORT
```

如果只查 stage，可能拿到错误产物。

正式内测版应该精确检查：

```text
composition + VIDEO_COMPOSITION_SPEC
preview + HYPERFRAMES_PROJECT
preview + PREVIEW_SNAPSHOTS
```

## 4.3 Render Guard 检查逻辑

```go
func (c *RepositoryBackedRenderDependencyChecker) checkRenderGuard(
    ctx context.Context,
    req RenderDependencyCheckRequest,
) error {
    missing := []string{}

    composition := c.findCurrentByStageAndKind(
        ctx,
        req.ProjectID,
        "composition",
        "VIDEO_COMPOSITION_SPEC",
    )
    if composition == nil || composition.Status != "valid" {
        missing = append(missing, "视频结构不存在或已过期")
    }
    if composition != nil && !composition.HumanApproved {
        missing = append(missing, "视频结构尚未确认")
    }

    project := c.findCurrentByStageAndKind(
        ctx,
        req.ProjectID,
        "preview",
        "HYPERFRAMES_PROJECT",
    )
    if project == nil || project.Status != "valid" {
        missing = append(missing, "渲染项目不存在或已过期")
    }

    preview := c.findCurrentByStageAndKind(
        ctx,
        req.ProjectID,
        "preview",
        "PREVIEW_SNAPSHOTS",
    )
    if preview == nil || preview.Status != "valid" {
        missing = append(missing, "预览快照不存在或已过期")
    }
    if preview != nil && !preview.HumanApproved {
        missing = append(missing, "预览尚未确认")
    }

    approved, err := c.reviewChecker.IsReviewApproved(ctx, req.ProjectID, "preview")
    if err != nil || !approved {
        missing = append(missing, "预览审核未通过")
    }

    supported, err := c.runnerChecker.SupportsCommand(ctx, "HYPERFRAMES_RENDER")
    if err != nil || !supported {
        missing = append(missing, "本地执行器未就绪或不支持渲染")
    }

    if len(missing) > 0 {
        return &RenderDependencyError{
            Code:    "RENDER_DEPENDENCY_MISSING",
            Message: "当前项目尚不满足最终渲染条件",
            Missing: missing,
        }
    }

    return nil
}
```
