# 躺营导演台 v1.0-beta 发布前最后修正交付报告

## 结论

本轮发布前最后修正已完成。系统现在可定义为：

```text
躺营导演台 v1.0-beta
第一版小范围用户内测版
```

修正重点：

1. 关键 artifact 写入失败不再静默继续。
2. `VIDEO`、`FFMPEG_PROBE_REPORT`、`FINAL_REVIEW`、`PROJECT_PACKAGE` 被定义为关键产物。
3. `CRITICAL_ARTIFACT_SYNC_FAILED` 会从 artifact sync 返回错误，避免“本地任务成功但云端产物丢失”的假成功。
4. LocalJob artifact sync 使用真实 `workflowRunID`，`taskID` 单独写入，不再默认混用。
5. 前端识别 `CRITICAL_ARTIFACT_SYNC_FAILED` 和 `ARTIFACT_MANIFEST_INVALID`，导出页继续只依赖真实 `VIDEO` artifact。

## 代码变更

- 新增 `cloud-backend/internal/core/artifact/sync_service.go`。
- 在 `cloud-backend/internal/core/artifact/model.go` 增加关键产物常量和 `IsCriticalArtifactKind`。
- 修改 `cloud-backend/cmd/tangying-ai-os/main.go`：
  - LocalJob callback 通过 `workflowRunRepo.FindRunIDByTaskID` 解析真实 workflowRunID。
  - `syncArtifactsFromLocalJob` 调用 `ArtifactSyncService`。
  - 关键 artifact create 失败返回 error。
- 扩展 `cloud-backend/cmd/tangying-ai-os/artifact_sync_test.go`：
  - critical create failure returns error。
  - non-critical create failure continues。
  - workflowRunID/taskID distinct。
- 前端复用 `formatDirectorErrorMessage`，补齐 critical artifact sync 失败文案。

## 未执行项

尚未执行真实 HyperFrames Render Service 的人工端到端联调。发布前仍建议按修正方案完成：

- 正向：preview approve → HYPERFRAMES_RENDER → ArtifactIndex `VIDEO` → ffmpeg_probe → final_review → package → 导出页显示 `final.mp4`。
- 反向：缺 `unitId`、关键 artifact 写入失败、本地 runner offline、缺 `VIDEO`、`final_review.passed=false` 均应阻断或明确报错。

## 风险

- 当前失败路径采用“callback 返回 error + 明确日志/前端错误提示”，还未将 `artifactSyncStatus=failed` 持久化为 LocalJob 独立状态字段。这个可作为 beta.1 的状态模型增强。
