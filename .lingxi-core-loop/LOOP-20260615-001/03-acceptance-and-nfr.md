## 非功能需求确认

### NFR-001: 全流程时间
- 目标: < 60 分钟（500 页）
- 量化: 50 页标书 < 15 分钟，100 页 < 25 分钟，300 页 < 40 分钟
- 瓶颈分析: LLM 生成是主要耗时，需并发章节生成

### NFR-002: 并发支持
- 目标: 10 个并发标书生成
- 实现方式: 每个标书是独立 DAG 任务，节点级并发
- 资源约束: 每个 LLM 生成节点约 2s-120s

### NFR-003: 数据持久化
- 已有: PostgreSQL 持久化 Task/Node/Context
- 新增: 标书草稿、模板、企业资料库
- 重启安全: Outbox 模式保证事件不丢失

### NFR-004: API 统一响应
- 目标: 所有新 API 使用 `{code, message, data}` 信封
- 已有不一致: orchestrator 和 context handler 用 `gin.H{}`

### NFR-005: Trace 追踪
- 已有: Context 表记录所有节点事件 + TraceHandler
- 新增: 扩展 Context 记录更多阶段信息
