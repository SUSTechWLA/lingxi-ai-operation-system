# BUG-001 Stale Builtin Proposal Test Expectation

## Symptom

`go test ./internal/core/worker/tool/builtin` failed at `TestExecuteProposalGeneratorReturnsDecisionLoggedPacket`.

The test expected `recommendedOptionId=option_b`, while the current core proposal builder returns `option_a` by default when no LLM recommendation is available.

## Classification

`TEST_DEFECT`

## Evidence

- `cloud-backend/internal/core/video/pipeline/manifest_test.go` already asserts default `option_a`.
- `cloud-backend/internal/core/video/pipeline/proposal.go` defaults `recommended := "option_a"`.

## Fix

Aligned the builtin test expectation with the core proposal packet default.
