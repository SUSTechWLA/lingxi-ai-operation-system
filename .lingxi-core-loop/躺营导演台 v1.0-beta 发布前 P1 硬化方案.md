### 1.1 测试关键 Artifact 写入失败返回 error

新增测试：

```go
func TestArtifactSync_CriticalArtifactCreateFailureReturnsError(t *testing.T)
```

测试目标：

```text
VIDEO CreateArtifact 失败
  ↓
SyncFromNodeOutput 返回 error
  ↓
error 包含 CRITICAL_ARTIFACT_SYNC_FAILED
```

测试伪代码：

```go
type fakeArtifactCreator struct {
	create func(ctx context.Context, req *CreateArtifactRequest) (*Artifact, error)
}

func (f fakeArtifactCreator) CreateArtifact(ctx context.Context, req *CreateArtifactRequest) (*Artifact, error) {
	return f.create(ctx, req)
}

func TestArtifactSync_CriticalArtifactCreateFailureReturnsError(t *testing.T) {
	ctx := context.Background()

	creator := fakeArtifactCreator{
		create: func(ctx context.Context, req *CreateArtifactRequest) (*Artifact, error) {
			if req.Kind == KindVideo {
				return nil, errors.New("db insert failed")
			}
			return &Artifact{ID: "art-ok", Kind: req.Kind, UnitID: req.UnitID}, nil
		},
	}

	svc := NewArtifactSyncService(creator, zap.NewNop())
	node := buildRenderNodeWithVideoArtifact()

	created, err := svc.SyncFromNodeOutput(ctx, "project-1", "run-1", "task-1", node)

	require.Error(t, err)
	require.Contains(t, err.Error(), "CRITICAL_ARTIFACT_SYNC_FAILED")
	require.Contains(t, err.Error(), "VIDEO")
	require.Empty(t, created)
}
```

### 1.3 测试 workflowRunID / taskID 分离

新增测试：

```go
func TestArtifactSync_UsesWorkflowRunIDNotTaskID(t *testing.T)
```

测试目标：

```text
workflowRunID = run-1
taskID = task-1
  ↓
CreateArtifactRequest.WorkflowRunID = run-1
CreateArtifactRequest.TaskID = task-1
```

测试伪代码：

```go
func TestArtifactSync_UsesWorkflowRunIDNotTaskID(t *testing.T) {
	ctx := context.Background()

	var captured *CreateArtifactRequest

	creator := fakeArtifactCreator{
		create: func(ctx context.Context, req *CreateArtifactRequest) (*Artifact, error) {
			copy := *req
			captured = &copy
			return &Artifact{ID: "art-video", Kind: req.Kind, UnitID: req.UnitID}, nil
		},
	}

	svc := NewArtifactSyncService(creator, zap.NewNop())
	node := buildRenderNodeWithVideoArtifact()

	_, err := svc.SyncFromNodeOutput(ctx, "project-1", "run-1", "task-1", node)

	require.NoError(t, err)
	require.NotNil(t, captured)
	require.Equal(t, "run-1", captured.WorkflowRunID)
	require.Equal(t, "task-1", captured.TaskID)
	require.NotEqual(t, captured.WorkflowRunID, captured.TaskID)
}
```

func TestLocalJobCompletion_HyperFramesRenderWritesVideoArtifact(t *testing.T) {
	ctx := context.Background()

	var captured *CreateArtifactRequest

		create: func(ctx context.Context, req *CreateArtifactRequest) (*Artifact, error) {
			copy := *req

## 任务 4：收紧 workflowRunID fallback 可观测性

当前主流程已经通过：

```go
workflowRunRepo.FindRunIDByTaskID(ctx, taskID)
```

获取 `workflowRunID`。

如果查不到，目前允许 fallback 到 `taskID`。这个 fallback 第一版可以保留，但要增强日志。

日志必须包含：

```text
artifact sync: workflowRunID missing, fallback to taskID
taskID
nodeID
projectID
toolName
command
```

建议新增 metrics 或 warning counter：

```text
artifact_sync_workflow_run_id_fallback_total
```

如果暂时没有 metrics 系统，至少保证日志清晰。
