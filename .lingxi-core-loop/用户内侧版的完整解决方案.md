# 躺营导演台 v1.0-beta 用户内测版补齐方案

## 1. 版本目标

当前版本定位：

```text
躺营导演台 v1.0-beta-rc1
第一版用户内测候选版
```

本次升级目标：

```text
躺营导演台 v1.0-beta
第一版正式用户内测版
```

正式用户内测版的定义不是“功能都存在”，而是：

```text
真实用户可以从一句话需求开始，完成一个中文图文视频项目，并最终拿到可播放的 final.mp4 和交付包。
```

第一版只做：

```text
中文图文视频
16:9 横屏
45-90 秒
分阶段人工确认
HyperFrames 本地渲染
本地 final.mp4 导出
项目 package 打包
```

第一版不做：

```text
Seedance 动态视频
TTS 自动配音
ASR 自动字幕
平台自动发布
多人审批
商业权限体系
复杂素材库
多模型路由
```

# 2. 用户内测版必须满足的 4 条红线

## 红线 1：上游修改，下游必须过期

用户修改脚本后，旧的卡片、结构、预览、最终视频、质量报告、交付包不能继续被使用。

```text
修改脚本
  ↓
卡片分镜 stale
视频结构 stale
预览快照 stale
最终视频 stale
质量报告 stale
交付包 stale
```

## 红线 2：预览未确认，绝不能渲染

只要预览没有人工确认，后端不能创建 `HYPERFRAMES_RENDER` LocalJob。

```text
PREVIEW_SNAPSHOTS.humanApproved != true
  ↓
禁止渲染
```

## 红线 3：质量未通过，绝不能打包

只要 `FINAL_REVIEW.passed != true`，后端不能创建 `ARTIFACT_PACKAGE` LocalJob。

```text
FINAL_REVIEW.passed != true
  ↓
禁止打包
```

## 红线 4：状态必须来自数据库事实，不来自前端推断

前端只展示状态，不计算核心状态。

```text
Artifact.status
Artifact.humanApproved
Artifact.dependsOn
Review.status
LocalRunner.status
```

必须由后端数据库或后端服务返回。

# 3. 最终主流程

正式用户内测版主流程如下：

```text
用户一句话输入
  ↓
定方向：生成创意方案
  ↓
审核创意方案
  ↓
写脚本：生成口播脚本
  ↓
审核口播脚本
  ↓
拆画面：生成卡片分镜
  ↓
审核卡片分镜
  ↓
排时间轴：生成视频结构
  ↓
审核视频结构
  ↓
定素材：生成素材计划
  ↓
查一致：生成一致性报告
  ↓
看预览：生成 HyperFrames 项目和预览快照
  ↓
审核预览
  ↓
出成片：本地渲染 final.mp4
  ↓
做体检：ffmpeg_probe + final_review
  ↓
打包：导出项目 package
```

流程节点只显示动作：

```text
定方向 / 写脚本 / 拆画面 / 排时间轴 / 定素材 / 查一致 / 看预览 / 出成片 / 做体检 / 打包
```

角色只在详情中展示：

```text
当前负责：脚本编剧
```

不要在流程卡片上重复展示：

```text
脚本编剧
负责流程：写脚本
```

# 4. P0-1：ArtifactIndex 数据库事实源补齐

## 4.1 当前问题

当前 `Artifact` 模型已经有状态字段，但 repository 仍主要读写旧字段。正式内测版必须让这些字段真正落库：

```text

status

```

## 4.2 数据库 Migration

新增 migration：

```sql
ALTER TABLE artifacts
ADD COLUMN IF NOT EXISTS task_id TEXT,
ADD COLUMN IF NOT EXISTS role_agent_id TEXT,
ADD COLUMN IF NOT EXISTS status TEXT NOT NULL DEFAULT 'valid',
ADD COLUMN IF NOT EXISTS human_approved BOOLEAN NOT NULL DEFAULT false,
ADD COLUMN IF NOT EXISTS depends_on JSONB NOT NULL DEFAULT '[]',
ADD COLUMN IF NOT EXISTS produced_by_node TEXT,
ADD COLUMN IF NOT EXISTS produced_by_tool TEXT,
ADD COLUMN IF NOT EXISTS produced_by_role TEXT,
ADD COLUMN IF NOT EXISTS updated_at TIMESTAMPTZ NOT NULL DEFAULT now();

CREATE INDEX IF NOT EXISTS idx_artifacts_project_kind_current
ON artifacts(project_id, kind, is_current);

CREATE INDEX IF NOT EXISTS idx_artifacts_project_status
ON artifacts(project_id, status);

CREATE INDEX IF NOT EXISTS idx_artifacts_project_human_approved
ON artifacts(project_id, human_approved);
```

## 5.3 MarkDownstreamStale 实现

不要再用 synthetic artifact id 作为主逻辑。

正确逻辑：

```go
func (s *Service) MarkDownstreamStale(
    ctx context.Context,
    projectID string,
    changedArtifactID string,
    reason string,
) ([]string, error) {
    changed, err := s.repo.FindByID(ctx, changedArtifactID)
    if err != nil {
        return nil, err
    }

    downstreamKinds := DownstreamStaleArtifactKinds(string(changed.Kind))
    if len(downstreamKinds) == 0 {
        return nil, nil
    }

    return s.repo.MarkCurrentArtifactsStaleByKinds(
        ctx,
        projectID,
        downstreamKinds,
        reason,
    )
}
```

Repository SQL：

```sql
UPDATE artifacts
SET
  status = 'stale',
  human_approved = false,
  metadata = jsonb_set(
      COALESCE(metadata, '{}'::jsonb),
      '{staleReason}',
      to_jsonb($3::text),
      true
  ),
  updated_at = now()
WHERE project_id = $1
  AND kind = ANY($2)
  AND is_current = true
  AND status <> 'stale'
RETURNING id;
```

## 6.2 ReviewApprovalChecker 实现

新增：

```go
type ReviewApprovalChecker struct {
    store ArtifactReviewStore
}

func (c *ReviewApprovalChecker) IsReviewApproved(
    ctx context.Context,
    projectID string,
    stage string,
) (bool, error) {
    review, err := c.store.FindLatestByProjectStage(ctx, projectID, stage)
    if err != nil {
        return false, err
    }
    return review != nil && review.Status == "APPROVED", nil
}
```

## 6.4 RepositoryBackedRenderDependencyChecker 升级

```go
func (c *RepositoryBackedRenderDependencyChecker) checkRenderGuard(
    ctx context.Context,
    req RenderDependencyCheckRequest,
) error {
    missing := []string{}

    composition := c.findArtifact(ctx, req.ProjectID, "VIDEO_COMPOSITION_SPEC")
    if composition == nil || composition.Status != "valid" {
        missing = append(missing, "视频结构无效或已过期")
    }
    if composition != nil && !composition.HumanApproved {
        missing = append(missing, "视频结构尚未确认")
    }

    project := c.findArtifact(ctx, req.ProjectID, "HYPERFRAMES_PROJECT")
    if project == nil || project.Status != "valid" {
        missing = append(missing, "渲染项目不存在或已过期")
    }

    preview := c.findArtifact(ctx, req.ProjectID, "PREVIEW_SNAPSHOTS")
    if preview == nil || preview.Status != "valid" {
        missing = append(missing, "预览快照不存在或已过期")
    }
    if preview != nil && !preview.HumanApproved {
        missing = append(missing, "预览尚未确认")
    }

    approved, err := c.reviewChecker.IsReviewApproved(ctx, req.ProjectID, "preview")
    if err != nil || !approved {
        missing = append(missing, "预览审核未通过")
    }

    supported, err := c.runnerChecker.SupportsCommand(ctx, "HYPERFRAMES_RENDER")
    if err != nil || !supported {
        missing = append(missing, "本地执行器未就绪或不支持渲染")
    }

    if len(missing) > 0 {
        return &RenderDependencyError{
            Code: "RENDER_DEPENDENCY_MISSING",
            Message: "当前项目尚不满足最终渲染条件",
            Missing: missing,
        }
    }

    return nil
}
```

## 7.3 PackageGuard 逻辑

```go
func (c *RepositoryBackedRenderDependencyChecker) checkPackageGuard(
    ctx context.Context,
    req RenderDependencyCheckRequest,
) error {
    missing := []string{}

    video := c.findArtifact(ctx, req.ProjectID, "VIDEO")
    if video == nil || video.Status != "valid" {
        missing = append(missing, "最终视频不存在或已过期")
    }

    probe := c.findArtifact(ctx, req.ProjectID, "FFMPEG_PROBE_REPORT")
    if probe == nil || probe.Status != "valid" {
        missing = append(missing, "视频检测报告不存在或已过期")
    }

    finalReview := c.findArtifact(ctx, req.ProjectID, "FINAL_REVIEW")
    if finalReview == nil || finalReview.Status != "valid" {
        missing = append(missing, "质量报告不存在或已过期")
    } else if !metadataBool(finalReview.Metadata, "passed") {
        missing = append(missing, "质量报告未通过")
    }

    if len(missing) > 0 {
        return &RenderDependencyError{
            Code: "PACKAGE_DEPENDENCY_MISSING",
            Message: "最终视频尚未通过质量检查，禁止打包。",
            Missing: missing,
        }
    }

    return nil
}
```

```json
    "fileSizeValid": true,
    "durationValid": true,
    "resolutionValid": true,
    "hasVideoTrack": true,
    "hasReadableMetadata": true
  },
```

# 16. 最终发布判断


```text

动态视频生成
```

```text

1. 上游修改，下游必 stale。
```
