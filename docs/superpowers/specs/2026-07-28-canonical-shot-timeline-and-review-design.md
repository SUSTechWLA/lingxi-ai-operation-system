# Canonical Shot Timeline and Review Design

## Goal

Make every Shot a trustworthy, independently reviewable production unit: its narration is the exact slice of the canonical audio timeline, its IP A-roll, HyperFrames text, and AIGC enrichment describe one coordinated image, and long details open without duplicating or reflowing the review page.

## Confirmed Root Causes

The real completed project `vp-1b8ceb41` contains a correct five-part `shotList`, but its downstream `videoPrompts` and Shot asset packages repeat the complete narration in all five Shots. Three gaps allow this:

1. Legacy Shot initialization assigns the complete project topic to every Shot.
2. Downstream generation plans do not preserve canonical narration and millisecond timing, so a later prompt builder can fall back to the complete topic.
3. No boundary validator proves ordered, gap-free Shot timing or that normalized Shot narration concatenates back to the approved script.

The historical review UI also renders the same text twice: once as a clamped preview and once inside a native `details` element. Expanding therefore moves an identical value below the card, while variable preview heights misalign the actions.

## Architecture

### 1. Canonical timeline authority

`AudioMasterTimeline` is the only timing authority. A Shot must carry:

- `startMs`
- `endMs`
- `durationMs`
- `timelineRevision`
- `narrationText`

The narration is derived from the timed cues covered by the Shot interval. It is not independently regenerated by the Shot planner, generation planner, video prompt generator, renderer, or historical projection.

The Shot sequence must be ordered, contiguous, non-overlapping, within the audio master duration, and must cover every narration cue exactly once. After whitespace and punctuation-safe normalization, concatenating Shot narration must equal the approved script.

When only a script is available, estimated timed cues create the first audio master. Importing or generating real voice audio creates a new timeline revision and marks time-dependent text, A-roll, AIGC, composition, subtitle, and render artifacts stale.

### 2. Downstream context preservation

The generation planner and prompt generator merge data by `shotId`. The canonical Shot/window supplies narration and timing; generation plans only add render strategy and layer designs. Missing generation-plan fields cannot replace canonical values with the project topic.

Legacy data receives a deterministic repair during projection: if every downstream Shot repeats the same full narration but the historical `shotList` contains distinct segments, the distinct canonical segment wins. This repair is display-safe and does not rewrite archived artifacts.

### 3. Coordinated three-layer visual contract

Every Shot carries one shared `visualAnchor`:

- a concise visual thesis for the Shot;
- the intended base composition and visual hierarchy;
- one primary reference/keyframe image;
- timed visual beats inside the Shot interval.

All layer timing is relative to the Shot and also resolvable to the canonical project timeline.

#### IP A-roll

The plan specifies subject placement, framing, eye line, expression, gesture, camera movement, scene state, and lighting changes for each timed beat. The IP remains the continuity anchor for talking-head work and must not be displaced by supplementary media unless the Shot explicitly selects a full-screen cutaway mode.

#### HyperFrames / HyperKeyframes

The plan specifies exact text, semantic role, typography intent, position, safe area, entry/hold/exit timing, and the visual beat it follows. Generated keyframes use the canonical Shot interval and never infer different narration.

#### AIGC enrichment

The plan identifies the primary reference image and whether AIGC is background, partial insert, picture-in-picture, or full-screen cutaway. Its model prompt is a literary, time-aware Vibe description of subject, emotion, environment, light, motion, and evolving atmosphere. Mechanical delivery constraints such as resolution, fps, compositing, and file format remain outside the creative prompt. The prompt grants the model aesthetic freedom while retaining explicit identity, text-safety, and continuity boundaries.

#### Composition

The plan states the visual lead for each beat, layer order, occlusion rules, safe zones, synchronization points, and how the Shot settles before the cut. All three layers serve the same visual thesis instead of behaving as unrelated checklists.

## Historical Review Interaction

Cards show one concise preview only. A fixed footer contains a consistently aligned `查看完整内容` button. Activating it opens an accessible right-side detail drawer on desktop and bottom sheet on narrow screens.

The drawer contains the full value once, the field label and Shot identity, close control, Escape handling, focus restoration, backdrop dismissal, and previous/next detail navigation where useful. Opening it does not expand the card or move surrounding content.

## Validation and Acceptance

1. A five-Shot, 30-second narration has five ordered millisecond ranges and five distinct narration segments.
2. Normalized concatenation of all Shot narration equals the approved full narration.
3. Duplicate full-script narration is rejected or repaired before video prompts and Shot packages are created.
4. Every video prompt and package preserves the canonical `shotId`, timing, timeline revision, and narration.
5. Every Shot exposes one visual anchor, primary reference image, timed IP plan, timed HyperKeyframes plan, timed AIGC Vibe plan, and composition relationship.
6. Historical cards never render the same full text inline twice; all detail actions align and open a non-reflowing accessible drawer.
7. The real completed-project fixture projects the five original narration segments instead of five copies of the full script.

## Non-goals

- Building a full non-linear timeline editor.
- Rewriting archived artifacts in place.
- Forcing AIGC into every frame when a Shot is better served by IP and exact local graphics.
- Encoding renderer implementation details inside the creative AIGC prompt.
