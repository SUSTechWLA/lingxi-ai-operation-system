# Skill：躺营AI OS 创作工作台与 AI 助手面板升级

## 一、升级目标
将当前「上传素材 + 填写表单 + AI生成全部内容」的线性流程，升级为更专业的「素材上传 → AI创作工作台（选择平台/风格/关键词 → 一键生成）→ AI助手实时调整」布局。新UI结构清晰，分层明确，强化AI能力感知，同时保留所有原有手动编辑能力。

## 二、前置条件
1. 当前前端页面已包含：
   - 视频/图片上传组件
   - 标题/简介/关键词输入框（每个带 `AI润色` 按钮）
   - 右侧平台选择面板
   - 底部 `AI生成全部内容` 按钮
2. 后端接口：
   - `POST /api/ai/generate`（可能用于生成标题和简介）
   - `POST /api/ai/polish`（润色）
   - `POST /api/publish`（发布）
   - 其他现有接口
3. Zustand store 管理全局状态。

## 四、前端改造步骤（按顺序执行）

### 1. 布局重构：左右分栏
- 将当前页面从单列布局改为 **左7右3** 或 **左8右4** 的栅格布局。
- 左侧：创作主区域（包含 AI 创作助手卡片、内容生成工作台、素材区、表单）。
- 右侧：AI 助手面板（原平台选择面板上移或改为Tab切换）。

### 2. 左侧「AI创作助手」卡片组
- 新建 `AICreationCards` 组件，包含两个卡片：
  - **卡片1：AI生成标题和简介**  
    显示图标和文字“根据视频或图片内容，AI自动生成吸引人的标题和简介”，按钮“一键生成”。
  - **卡片2：AI润色优化**  
    显示图标和文字“优化现有标题和简介，提升内容质量和吸引力”，按钮“一键优化”。
- 点击“一键生成” → 调用后端接口基于已上传的素材生成标题+简介+关键词，直接填入下方表单。
- 点击“一键优化” → 调用润色接口，对当前已有标题/简介进行优化，返回结果并填入。

### 3. 新增「内容生成工作台」区块
- 在素材区和表单之间插入 `ContentWorkbench` 组件。
- 包含：
  - 目标平台下拉选择（复用平台数据，支持多选或单一默认）。
  - 风格/关键词输入框（placeholder: “轻松活泼、专业深度、带emoji...”）。
  - `AI智能生成` 按钮（蓝色醒目）。
  - 状态提示：“请先上传素材后再生成内容”（当无素材时禁用按钮）。
- 点击“AI智能生成” → 调用新接口 `POST /api/workbench/generate`，传入上传的素材ID、目标平台、风格关键词。该接口内部调用大模型生成完整内容（标题、简介、正文、关键词），并填入表单。

### 4. 调整素材区域位置
- 将上传视频/图片卡片移到左侧上方，并显示已上传文件数量（“0张图片，0个视频”）。
- 保留原有上传功能不变，仅调整视觉位置。

### 5. 右侧「AI助手」面板实现
- 新建 `AIAssistantPanel` 组件，替换原有纯平台选择面板。
- 面板顶部提供两个 Tab：`发布平台` | `AI助手`。
- `发布平台` Tab：保留原平台多选功能。
- `AI助手` Tab：
  - 显示欢迎语：“你好！我是你的创作助手……”
  - 消息列表（最近几条对话）。
  - 输入框，用户可发送修改指令（如“标题太正式了，改成活泼一点”）。
  - 发送后调用 `POST /api/chat/revise`（见后端部分），实时更新左侧表单字段。
  - 不显示完整历史，只保留最修改记录，保持轻量。

### 6. 移除旧元素
- 移除现有的独立“AI润色”按钮（每个输入框旁边的），将润色功能统一纳入“AI润色优化”卡片和AI助手面板。
- 移除旧的“AI生成全部内容”按钮（底部那个），功能由“内容生成工作台”的“AI智能生成”按钮替代。
- 但保留“下一步：选择发布平台→”和“一键发布到选中平台”，因为它们还用于发布流程。

### 7. 样式对齐
- 所有卡片使用 Tailwind 的 `rounded-xl`, `shadow-sm`, `border`，与当前设计风格一致。
- 按钮采用品牌色（原项目中使用的蓝色或紫色），字体大小统一。
- 右侧面板宽度约 320px，内部滚动。

## 五、后端接口调整

### 新增接口

1. **`POST /api/workbench/generate`**  
   - 请求体：
     ```json
     {
       "media_ids": ["video1", "img2"],
       "platform": "xiaohongshu",
       "style_keywords": "治愈温暖，个人成长"
     }
     ```
   - 响应 (200)：
     ```json
     {
       "message": "success",
       "data": {
         "title": "一个人的旅行...",
         "description": "独自踏上旅途...",
         "body": "丽江古城的清晨...",
         "keywords": ["独自旅行", "内心平静"]
       }
     }
     ```
   - 实现：复用现有 `PublishService.AIGenerateContent()` 或类似逻辑，增加风格参数传入大模型。

2. **`POST /api/chat/revise`** （与对话Skill中相同）  
   - 用于 AI 助手 Tab 的自然语言修改。

3. **`POST /api/ai/generate-from-media`** （若已有则保留，用于“一键生成”卡片）  
   - 复用现有生成标题和简介的能力。

### 删除的接口（或标记废弃）
- **`POST /api/ai/generate`** 如果它只是简单的生成标题和简介，且被新工作台取代，可以删除或改为内部调用。但建议保留，因为“AI生成标题和简介”卡片可能还需复用，只是不再作为独立按钮。
- **`POST /api/ai/polish`** 保留，因为“AI润色优化”卡片需要使用它。
- **旧版的批量生成相关端点**，如果之前有开发，评估后若无引用则删除。

### 代码清理
- 删除前端对应的旧组件（如单独的 `AIHelperPanel` 旧版，如果被替换）。
- 移除不再使用的 API 调用函数（如 `generateAllContent`）。
- 确保 Zustand store 中移除仅用于旧UI的临时状态。

## 六、迁移连贯性保障
- **不丢失用户数据**：所有已上传素材、已填写的表单内容在升级后依然可见，因为 store 字段未变。
- **保留手动编辑**：标题、简介、关键词输入框依然存在，用户可自由修改。
- **AI 生成结果直接填入**：与旧版行为一致，用户感知为“生成速度更快、选项更多了”。
- **发布流程不变**：“下一步”和“一键发布”按钮仍在底部，功能不受影响。

## 七、验收标准
1. 页面布局变为左右分栏，左侧从上到下依次为：素材区、AI创作助手卡片、内容生成工作台、表单、底部按钮。
2. 右侧面板包含“发布平台”和“AI助手”两个Tab，可切换。
3. 上传素材后，点击“AI智能生成”按钮，能够根据平台和风格生成标题、简介、正文并填入。
4. 在AI助手Tab输入修改指令，对应字段实时更新。
5. 原有的独立AI润色按钮已消失，功能由“AI润色优化”卡片和AI助手替代。
6. 旧版API接口若无调用则已删除，代码库精简。
7. Web端和Electron端显示正常，无布局错乱。
