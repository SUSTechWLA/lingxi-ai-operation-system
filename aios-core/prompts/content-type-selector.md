# Skill：内容发布类型选择与动态表单优化

## 一、升级目标
在现有创作发布页面顶部增加**内容类型选择器**（图文笔记 / 短视频），用户选择后，动态调整下方的素材上传区、AI 工作台选项和表单字段，使得交互更加聚焦，减少无关操作。

## 二、前置条件
1. 当前页面包含：视频上传区、图片上传区、标题/简介/关键词输入框、平台选择器。
2. Zustand store 中存在 `videos`、`images` 等上传文件状态。
3. 后端已有素材上传接口（可接收视频和图片），发布接口 `/api/publish` 已支持 `video_files` 和 `image_files` 字段。

## 三、交互设计方案

### 1. 类型选择器位置
放置在左侧创作区最顶部，**高于上传素材区**，用户进入页面时需首先明确内容类型。

### 2. 视觉样式
两个大卡片（图文、短视频），横向并排，点击后高亮选中（边框加粗、颜色变化），或使用分段控件（Segment Control）。卡片内包含图标 + 名称 + 简短描述：
- **图文笔记**：图标（图片+文字），描述“发布多张图片 + 文字描述”
- **短视频**：图标（视频），描述“发布一段视频 + 文字描述”

默认可不选中任何一项，提示“请选择发布类型”，直到用户点击后下方区域才激活。

### 3. 动态表单变化
- **选择「图文」**：
  - 视频上传区域**隐藏**。
  - 图片上传区域放大，多图上传（最多9张，或有设计图显示“替换图片”按钮）。
  - AI 工作台的风格/关键词输入可保持。
  - 正文区域（如果有）可自动显示，默认显示一个简单的富文本编辑区。
- **选择「短视频」**：
  - 图片上传区域**隐藏**。
  - 视频上传区域放大，支持单个视频文件，时长限制提示。
  - 可能存在视频封面区域（可选上传封面图片，此时可临时显示图片上传，但限制为1张）。
  - AI 工作台可保留，用于基于视频内容生成标题和简介。

### 4. AI 生成的联动
- 图文模式下，AI 生成重点在图片内容解析和文字风格。
- 短视频模式下，AI 可基于视频画面或原声生成内容，若不行则只生成标题/简介。
- “AI 生成全部内容”按钮文案可动态变为“生成图文内容”或“生成短视频文案”。

### 5. 右侧 AI 助手面板保持不变
因为无论哪种类型，后续修改、优化逻辑相同。

## 四、前端实施步骤

### 第一步：增加类型选择状态
在 Zustand store 中添加：
```typescript
contentType: 'image' | 'video' | null;
setContentType: (type: 'image' | 'video') => void;
```

### 第二步：实现类型选择卡片
新建 `ContentTypeSelector.tsx`，置于页面最上方。
```tsx
<div className="flex gap-4 mb-6">
  <div 
    className={`flex-1 p-6 border-2 rounded-xl cursor-pointer ${contentType === 'image' ? 'border-blue-500 bg-blue-50' : 'border-gray-200'}`}
    onClick={() => setContentType('image')}
  >
    {/* 图片图标 */}
    <h3>图文笔记</h3>
    <p className="text-sm text-gray-500">发布多张图片 + 文字描述</p>
  </div>
  <div 
    className={`flex-1 p-6 border-2 rounded-xl cursor-pointer ${contentType === 'video' ? 'border-blue-500 bg-blue-50' : 'border-gray-200'}`}
    onClick={() => setContentType('video')}
  >
    {/* 视频图标 */}
    <h3>短视频</h3>
    <p className="text-sm text-gray-500">发布一段视频 + 文字描述</p>
  </div>
</div>
```

### 第三步：条件渲染素材上传区
根据 `contentType` 控制：
```tsx
{contentType === 'image' && (
  <ImageUploader maxCount={9} />
)}
{contentType === 'video' && (
  <VideoUploader maxSize="2GB" maxDuration={30*60} />
)}
```
未选择时显示提示“请选择发布类型”，上传区不可见。

### 第四步：调整 AI 工作台文案与逻辑
- 将“目标平台”下拉保持不变。
- “AI 智能生成”按钮调用不同后端的参数中带上 `content_type`，让 AI 适配生成。
- 按钮文案可改为“生成图文内容”或“生成短视频文案”。

### 第五步：底部按钮保持一致
清空内容、发布按钮位置不变，发布时根据 `contentType` 在 `PublishRequest` 中传递相应的字段。

## 五、后端调整

### 接口修改
- `POST /api/workbench/generate`：请求体增加 `content_type: "image" | "video"` 字段，大模型根据类型生成不同侧重点的内容。
- 发布接口 `POST /api/publish`：已经有 `image_files` 和 `video_files`，只需前端根据类型只传对应字段即可，无需后端改动。

### 验证规则
- 后端在发布时校验：图文类型必须有 `image_files` 且无视频；短视频类型必须有 `video_file` 且无多图（除了封面）。

## 六、连贯性保障
- 类型选择卡片位于原“AI创作助手”上方，不影响原有组件位置。
- 未选择类型时，素材上传区、AI工作台和表单均不可用（灰显），引导用户先选择。
- 切换类型时，**不清空已填写的内容**（标题、简介、关键词保留），但清空已上传的文件（提示用户“切换类型将清空已上传的素材”），避免混淆。

## 七、验收标准
1. 页面打开后，顶部显示两个类型选择卡片，默认未选中。
2. 选择“图文笔记”后，显示图片上传区，视频上传区消失。
3. 选择“短视频”后，显示视频上传区，图片上传区消失（或仅显示封面图上传）。
4. AI 工作台根据所选类型调整生成策略（生成结果偏向图文布局或视频标题/文案）。
5. 切换类型会提示清空素材，但已填文字不丢失。
6. 最终发布请求携带正确的文件字段。
